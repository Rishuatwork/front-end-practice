🌦️ Weather App

A simple weather application built using JavaScript that fetches real-time weather data based on user input.

This is part of my learning journey where I’m focusing on building projects to understand concepts deeply instead of just watching tutorials.

⚙️ Features

- Search weather by city name
- Displays temperature in Celsius
- Shows humidity percentage
- Shows wind speed
- Dynamic weather icons (clear, cloudy, rainy, etc.)


🧱 Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeatherMap API


🧠 What I Learned

This project was less about “building a weather app” and more about understanding how things actually work under the hood.

- How to work with APIs using fetch
- Understanding async/await, promises, and callbacks in a practical way
- DOM manipulation and updating UI dynamically
- Handling user input and events

As I progressed, I started noticing patterns and predicting what comes next, which is something I never experienced while just watching tutorials.

😵 Challenges Faced

Coming out of tutorial-heavy learning wasn’t easy.

Had to revisit core concepts like:

- callbacks
- promises
- async/await

Struggled with API not responding initially
Later found out API keys take time to activate
Faced issues connecting logic with DOM updates
Had to deeply understand event listeners and query selectors instead of just using them

A lot of time went into figuring out small things, but that’s where most of the learning happened.

📈 Approach

Instead of blindly following a tutorial, I made sure to:

- Break down every line of code before using it
- Understand why something works, not just how
- Slightly tweak things instead of copying 1:1

By the end, things started feeling more natural and less mechanical.
